# Deep Time

**A Minecraft mod (NeoForge 1.21.1) that replaces the overworld with the age of dinosaurs**, plus two optional add-ons:
human peoples who grew up beside them, and the Age of Mammals that came after.

## Download

**[Latest release (all files)](https://github.com/Rockydo/deep-time/releases/latest)**

| File | What it is | Needs |
|---|---|---|
| `deeptime-1.1.0.jar` | **Deep Time**, the base mod: 143 Mesozoic biomes from real fossil sites, 20 cave biomes, over 1,100 species, hunting, taming, riding, seasons, seas and rivers | GeckoLib |
| `deeptime_peoples-1.1.0.jar` | **Deep Time: Peoples** (optional): 94 human cultures in five ages, with their settlements, trades, guards, caravans and ships | Deep Time 1.1.0 |
| `deeptime_cenozoic-1.1.0.jar` | **Deep Time: Age of Mammals** (optional): the 66 million years after the dinosaurs, 89 biomes, 231 animals, ice sheets to tar pits | Deep Time 1.1.0 |
| `deeptime-full-experience-1.1.0.mrpack` | **The full experience modpack**: everything above plus shaders, Distant Horizons, JEI, Jade, maps and performance mods, set up to work together | Prism Launcher, Modrinth App or any launcher that opens `.mrpack` |

## Install

**Easiest: the modpack.** Download `deeptime-full-experience-1.1.0.mrpack` and import it in
[Prism Launcher](https://prismlauncher.org/) (Add Instance → Import) or the [Modrinth App](https://modrinth.com/app).

**By hand:**
1. Install Minecraft **1.21.1** with **NeoForge 21.1.258 or newer** (Java 21).
2. Put these in the `mods` folder: `deeptime-1.1.0.jar` and [GeckoLib 4.9.3 or newer (4.x)](https://modrinth.com/mod/geckolib/versions?g=1.21.1&l=neoforge).
3. Optional: add `deeptime_peoples-1.1.0.jar` and/or `deeptime_cenozoic-1.1.0.jar`. The add-ons must have the same version as the base mod.
4. Create a world: the **Deep Time** world type is preselected.
